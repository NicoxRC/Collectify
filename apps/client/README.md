# Collectify — Client

React + Vite admin panel for Collectify. See the repository root [`README.md`](../../README.md) for full local setup instructions and [`docs/`](../../docs) for project documentation — in particular [`docs/phasesClient`](../../docs/phasesClient) for the frontend build plan this app follows.

## Scripts

- `npm run dev` — start the local dev server (`http://localhost:5173`)
- `npm run build` — type-check and build for production
- `npm run preview` — preview the production build locally
- `npm run lint` / `npm run lint:fix` — ESLint
- `npm run format` — Prettier
- `npm run test` — run unit tests once with Vitest
- `npm run test:watch` — run tests in watch mode

## Environment variables

Copy `.env.example` to `.env.local` and fill in the values — see [`docs/ENVIRONMENT_VARIABLES.md`](../../docs/ENVIRONMENT_VARIABLES.md).
